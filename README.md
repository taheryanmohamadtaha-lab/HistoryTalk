# گفتگوی تاریخ (HistoryTalk)

اپلیکیشن اندروید فارسی (راست‌به‌چپ) برای **گفتگوی متنی آفلاین** با شخصیت‌های تاریخی. کاربر یک شخصیت را برمی‌گزیند، پروفایل تاریخی او را می‌بیند و با او چت می‌کند. شخصیت با لحن و زمینه‌ی دوران خودش پاسخ می‌دهد.

> «این گفتگو یک بازآفرینی آموزشی و خیالی بر پایه منابع تاریخی است و نظر واقعی آن شخص یا نظر برنامه نیست.»
> این پیام در اولین ورود و بالای هر چت نمایش داده می‌شود.

## قابلیت‌ها
- ۱۵ شخصیت داخلی: چنگیزخان، ناپلئون، کوروش، اسکندر، نادرشاه، امیرکبیر، سقراط، لئوناردو، اینشتین، لنین، استالین، هیتلر، چرچیل، گاندی، ابن‌سینا
- انتخاب شخصیت با جست‌وجو، فیلتر دوره/نقش و علاقه‌مندی‌ها؛ پروفایل با خط زمانی، مکان‌ها و نقل‌قول‌ها (نقل مستند یا برچسب «بازآفرینی»)
- چت با ذخیره‌ی خودکار، چند گفتگوی جدا برای هر شخصیت، پیشنهاد پرسش، حالت **مصاحبه‌ی تاریخی** و حالت **چالش**
- دکمه‌ی **حقیقت‌سنجی تاریخی** زیر هر پاسخ: نمایش بخش دانشی و منبعی که پاسخ بر پایه‌ی آن بوده
- جست‌وجو در تاریخچه، خروجی TXT/PDF، حذف گفتگو/تاریخچه، تم روشن/تاریک، تغییر اندازه‌ی فونت
- افزودن شخصیت تازه با فایل JSON (بخش «افزودن شخصیت»)

## موتور گفتگو (سه لایه، کاملاً آفلاین)
1. **پایگاه دانش محلی (Room + FTS4):** ورودی‌های ساختاریافته (زندگی، جنگ، سیاست، خانواده، عقاید، میراث، علم، مرگ). بازیابی با FTS و سپس رتبه‌بندی (عنوان > کلیدواژه > متن + امتیاز دسته).
2. **مدل کوچک روی دستگاه (اختیاری):** با MediaPipe LLM Inference. پاسخ فقط بر پایه‌ی دانش بازیابی‌شده (RAG) تولید می‌شود؛ اگر دانش مرتبطی نباشد مدل صدا زده نمی‌شود تا واقعیت جعلی ساخته نشود. استریم، دکمه‌ی توقف، «نگهبان کرش» هنگام بارگذاری مدل.
3. **حالت پایه (بدون مدل):** دسته‌بندی پرسش + الگوی گفتار شخصیت + دانش محلی. برنامه همیشه می‌گوید کدام حالت فعال است. تشخیص RAM/ABI دستگاه و پیشنهاد خودکار حالت.

## ایمنی محتوا
فیلتر قاعده‌محور آفلاین روی ورودی و خروجی: انکار هولوکاست/نسل‌کشی، نفرت‌پراکنی، دستور ساخت سلاح، اظهارنظر درباره‌ی افراد زنده/امروز، ستایش ایدئولوژی‌های نفرت‌محور و محتوای نامناسب مسدود می‌شود؛ برنامه از نقش بیرون می‌آید و به واقعیت تاریخی ارجاع می‌دهد. پاسخ شخصیت‌های جنجالی (هیتلر، استالین، لنین، چنگیزخان) جنایات و پیامدهای مستند را بیان می‌کند. فیلتر بی‌نقص نیست (بخش محدودیت‌ها).

## حریم خصوصی
همه‌ی داده‌ها فقط روی دستگاه می‌ماند. بدون سرور، ردیاب و آنالیتیکس. مجوز اینترنت فقط برای دانلود اختیاری مدل است. هیچ کلید API یا توکنی در کد نیست.

## دریافت APK
- **Actions:** در تب Actions آخرین اجرای «Build APK» را باز کنید → Artifacts → `HistoryTalk-apk`
- **Releases:** با ثبت تگ `v1.0.0` فایل‌ها در صفحه‌ی Releases هم قرار می‌گیرند.
- بدون keystore فقط `HistoryTalk-debug.apk` (قابل نصب) ساخته می‌شود؛ با keystore فایل `HistoryTalk-release.apk` امضاشده هم ساخته می‌شود.

## ساخت محلی
نیازمند JDK 17 و Android SDK (compileSdk 35).
```bash
# (اختیاری) فونت وزیرمتن را در assets قرار دهید؛ بدون آن فونت سیستم استفاده می‌شود
mkdir -p app/src/main/assets/fonts
curl -L -o app/src/main/assets/fonts/Vazirmatn-Regular.ttf https://raw.githubusercontent.com/rastikerdar/vazirmatn/v33.003/fonts/ttf/Vazirmatn-Regular.ttf
curl -L -o app/src/main/assets/fonts/Vazirmatn-Bold.ttf    https://raw.githubusercontent.com/rastikerdar/vazirmatn/v33.003/fonts/ttf/Vazirmatn-Bold.ttf

./gradlew testDebugUnitTest     # تست‌های واحد
./gradlew assembleDebug         # app/build/outputs/apk/debug/
python3 tools/verify_packs.py   # اعتبارسنجی پک‌های داده
```

## آپلود روی GitHub
```bash
git init && git add . && git commit -m "HistoryTalk: نسخه‌ی اول"
git branch -M main
git remote add origin https://github.com/<USER>/<REPO>.git
git push -u origin main
```
سپس در **Settings → Actions → General** مطمئن شوید اجرای workflow مجاز است. (اگر `gradle/wrapper/gradle-wrapper.jar` در مخزن نیست، یک‌بار `gradle wrapper` اجرا کنید.)

## امضای APK با GitHub Secrets
```bash
keytool -genkeypair -v -keystore release.jks -alias historytalk -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks > keystore.b64     # محتوای این فایل را در Secret بگذارید
```
در **Settings → Secrets and variables → Actions** این‌ها را بسازید: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`. فایل keystore را هرگز در مخزن نگذارید (در `.gitignore` هست).

## افزودن شخصیت (پک JSON)
از «تنظیمات → افزودن شخصیت از فایل JSON» یک فایل (یا آرایه‌ای از شخصیت‌ها) وارد کنید. برای شخصیت‌های داخلی، فایل را در `app/src/main/assets/figures/<id>.json` بگذارید (نام فایل = `id`).
```json
{
  "id": "my_figure",                // انگلیسی کوچک/عدد/_ ؛ یکتا
  "name": "نام", "nameEn": "Name", "years": "...", "nationality": "...", "role": "...",
  "era": "...", "civilization": "...", "controversial": false, "color": "#7A5A1E",
  "summary": "...", "persona": "توصیف لحن برای مدل",
  "speech": { "greeting": "...", "openers": ["..."], "closers": ["..."] },
  "timeline": [ { "year": "۱۸۷۹", "text": "..." } ],
  "quotes": [ { "text": "...", "source": "...", "recreated": true } ],
  "places": ["..."],
  "entries": [ { "category": "life|war|politics|family|beliefs|legacy|science|death",
                 "title": "...", "text": "پاسخ به زبان اول‌شخص", "keywords": "کلمه‌ها با فاصله", "source": "منبع" } ],
  "suggestions": ["درباره جنگ‌هایت بگو"],
  "challenges": [ { "question": "...", "keywords": ["..."], "answer": "..." } ]
}
```
نکته‌ها: هر پیشنهاد (`suggestions`) باید واژه‌ای مشترک با عنوان/کلیدواژه‌ی یک ورودی داشته باشد؛ نقل‌قول غیرمستند را حتماً `recreated: true` کنید؛ متن‌ها نباید با فیلتر ایمنی در تضاد باشند (هنگام افزودن بررسی می‌شود). پک‌های داخلی را با `python3 tools/verify_packs.py` بررسی کنید.

## مدل زبانی اختیاری
1. در «تنظیمات → مدل زبانی» آدرس **HTTPS** یک فایل مدل با فرمت MediaPipe LLM (`.task`، مثلاً Gemma کوانتیزه‌ی کوچک) را وارد کنید و دانلود را بزنید (حجم و پیشرفت نمایش داده می‌شود، دانلود قابل ازسرگیری است).
2. مجوز مدل را خودتان باید بپذیرید؛ بسیاری از مدل‌ها (مانند Gemma) پشت صفحه‌ی ورود/پذیرش مجوز هستند و لینک مستقیم عمومی ندارند. این برنامه توکن یا ورود پشتیبانی نمی‌کند؛ باید خودتان لینک مستقیم قابل‌دانلود تهیه کنید.
3. قالب پرامپت (`PromptBuilder`) برای Gemma است؛ برای مدل‌های دیگر باید تنظیم شود.
4. موتور مدل فقط برای `arm64-v8a` بسته‌بندی می‌شود؛ دستگاه‌های دیگر خودکار حالت پایه دارند.

## محدودیت‌های شناخته‌شده
- **این پروژه در محیط ساخت (بدون Android SDK و دسترسی به مخازن Maven) با Gradle کامپایل نشد.** فقط لایه‌ی موتور (PersianText، SafetyFilter، Ranker، QuestionClassifier، TemplateEngine، ChallengeEngine) و تست‌های واحد آن‌ها با کامپایلر Kotlin 2.0.21 کامپایل و اجرا شدند (۱۸ تست موفق؛ ۱۲۰ پاسخ آزمایشی بدون مسدودسازی نادرست). کد Compose/Hilt/Room برای اولین بار در GitHub Actions کامپایل می‌شود و ممکن است نیاز به رفع خطاهای جزئی داشته باشد.
- APK ساخته‌شده و روی دستگاه آزموده نشده است؛ اهداف کارایی (لانچ زیر ۲ ثانیه، پاسخ پایه زیر ۱ ثانیه) اندازه‌گیری نشده‌اند.
- **عکس/نگاره:** به‌جای تصویر واقعی، نشان رنگی با حرف اول نام استفاده می‌شود (تصویر دامنه‌ی عمومی داخل مخزن نیست). «نقشه‌ی مختصر» فقط فهرست مکان‌هاست، نقشه‌ی گرافیکی نیست.
- حالت پایه مولد نیست: از متن‌های اول‌شخصِ نوشته‌شده‌ی پایگاه دانش پاسخ می‌دهد و برای پرسش‌های خارج از دانش، صادقانه می‌گوید پاسخ ندارد. هر شخصیت فقط ۶–۸ ورودی دانش دارد؛ پوشش موضوعی محدود است.
- قابلیت‌های اختیاری **میزگرد چندشخصیتی** و **TTS آفلاین** پیاده‌سازی نشده‌اند.
- بیشتر نقل‌قول‌ها «بازآفرینی» هستند؛ نقل مستقیم فقط چند مورد است. محتوای تاریخی بازنگری تخصصی نشده و ممکن است ساده‌سازی یا خطا داشته باشد؛ به منابع اصلی مراجعه کنید.
- فیلتر ایمنی قاعده‌محور و فقط فارسی است؛ دور زدن با املای غیرمعمول یا پرسش‌های غیرمستقیم ممکن است. خروجی مدل زبانی نیز می‌تواند اشتباه باشد (فیلتر خروجی و RAG فقط خطر را کم می‌کنند).
- بررسی پاسخ در حالت چالش بر پایه‌ی کلیدواژه است. جست‌وجوی تاریخچه ساده (`LIKE`) است.
- طرح تبلت فقط شبکه‌ی تطبیقی و محدودکردن عرض است؛ طرح دوپنجره‌ای ندارد.
- فونت وزیرمتن در CI دانلود و داخل APK قرار می‌گیرد؛ در ساخت محلی بدون آن، فونت سیستم استفاده می‌شود.
- تست UI (androidTest) فقط پایه است و در CI اجرا نمی‌شود.
